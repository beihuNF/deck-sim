# public-beta v0.111.0 升级验收

日期：2026-10-10。升级基线：`7ed6661`（v0.98.3）；分支：`codex/public-beta-v0.111.0`。本次改动尚未提交、推送或部署。

目标为本机 Steam public-beta 安装：`v0.111.0 / 41cef1ea`，上游发布日期 `2026-08-13`，Steam Build ID `24724944`。没有确认它是分支当前最新构建。

## 存档兼容性

- 旧样本目录 `packages/core/test/fixtures/saves-v0.98.3/` 和 `old-saves.test.ts` 原样保留；兼容读取不放宽测试，也不重新导出覆盖样本。
- 审查基线全部 70 个带 JSON 成员元数据的类型及 54 个模型保存属性，不仅检查样本中出现的类型。新版有 74 个 JSON 类型、61 个保存属性（含 2 个保留的旧属性）。
- 两个 RNG DTO 移除了 `Counters`，玩家种子从 UInt32 改为 UInt64：统一 `restore()` 保留旧字段，恢复旧 .NET Random 流；旧局重存保留 `Counters` 和 `LegacySeed`。新局使用精确 64 位 XXH64 / SplitMix64 / xoshiro256**，JSON 无损保存大整数。
- 新快照根对象带 `$webSaveVersion: 2`；旧快照缺少新字段时保留构造默认值，缺少 `GameMode` 时按原有 DailyTime / Modifiers 推断。
- 基线全部旧类的剩余缺口已审查：8 个缺失名仅涉及内部状态、Mod/多人消息、调试命令/地图和保存属性缓存，没有移除可被存档引用的模型。
- 移除的旧模型保留原完整类型名、模型 Id 和行为。冻结片段来自基线生成代码，经转译器纳入新产物；旧卡不回到 beta 奖励池。
- 持久糖果的 `CombatsSeen` 和南瓜蜡烛的 `ActiveAct` 保留原计数、效果及描述；新获得的遗物使用 beta 行为。
- Mod 元数据中删除的成员仍由统一读取路径保留；网页版不运行 Mod 加载器。
- `user://` 存档文件名及 `default/1/profile<N>/saves/` 路径、IndexedDB `sts2fs`、localStorage `sts2fs:`、退出日志 `sts2fs-j:`、早期 localStorage 数据迁入均未改变。`rt/godot.ts` 的改动仅补齐 FileAccess 打开缺失文件时的错误码，并有针对性测试。

浏览器验证使用独立 Playwright 上下文，不接触玩家现有浏览器档案。

- 新构建写过的快照不能保证旧构建可读；后续发布决策需要考虑仍开着旧页面的玩家。
