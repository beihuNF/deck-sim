# 联机网络低延迟与节点优化指南

默认情况下，Cloudflare 免费 Anycast 网络会将中国大陆的访问请求路由至美国西海岸（如圣何塞 SJC / 洛杉矶 LAX），导致物理往返时延（RTT）稳定在 **190ms ~ 220ms** 左右。

本项目已通过**服务端机房调度提示**与**客户端中继支持**完成了低延迟底层适配，配合 **Cloudflare 优选 IP** 或 **国内/香港中继**，可将联机延迟降低至 **30ms ~ 80ms**。

---

## 优化手段概览

| 方案 | 预期延迟 | 实施成本 | 说明 |
|---|---|---|---|
| **Durable Object 亚太机房锁定（已内置生效）** | 避免跨洋中转 | 零配置（自动） | 服务端已内置 `locationHint: 'apac'`，确保房间 Durable Object 优先创建在亚洲（香港/东京/新加坡）机房。 |
| **Cloudflare 优选 IP（推荐）** | **50ms ~ 90ms** | 仅需配置 DNS 解析 | 国内域名解析到 Cloudflare 亚太 Anycast 节点，免改游戏代码。 |
| **URL 参数接入点（免改 DNS）** | **50ms ~ 90ms** | 随时指定 | 打开页面时携带 `?relay=加速域名` 即可直接切换联机 WebSocket 网关。 |
| **独立国内/香港服务器部署房间服务** | **15ms ~ 35ms** | 需一台轻量云服务器 | 静态页面仍在 Cloudflare，仅将 Docker 房间服务部署在境内或香港。 |

## 方案一：Cloudflare 优选 IP 详细配置（站长推荐）

### 1. 原理
Cloudflare 在全球广播相同的 IP 地址池，但不同 IP 路由段在中国三大运营商的直连表现不同：
- **中国移动**：走香港 CMI 骨干直连最佳，延迟通常在 **35ms ~ 65ms**。
- **中国联通**：走日本东京 / 韩国首尔直连最佳，延迟通常在 **60ms ~ 85ms**。
- **中国电信**：走香港 / 圣何塞 CN2 或亚太优化段，延迟通常在 **70ms ~ 110ms**。

### 2. 使用 CloudflareSpeedTest 测出最佳 IP
在本地或服务器运行开源优选测速工具：
```bash
# 下载 CloudflareSpeedTest (Windows/macOS/Linux 均有预编译二进制)
# 测速命令示例（测速 HTTP 与延迟）：
./CloudflareST -tl 150 -tll 50 -sl 5 -dn 10
```
测速完成后会输出每个运营商延迟最低、无丢包的 Anycast IP（如 `104.16.x.x`, `162.159.x.x`）。

### 3. DNS 智能线路解析
在你的域名 DNS 托管控制台（如腾讯云 DNSPod、阿里云 DNS、华为云 DNS 等），将 `sts2.136521.xyz` 或专门的二级域名做分线路解析：
- **默认 / 境外**：解析到 Cloudflare 官方 CNAME
- **电信线路**：A 记录指向测出的电信优选 IP
- **联通线路**：A 记录指向测出的联通优选 IP
- **移动线路**：A 记录指向测出的移动优选 IP（如香港 CMI 优选 IP）

> **注意**：由于 Cloudflare 支持 SNI 和自适应证书握手，客户端只要带着原域名 Host 访问优选 IP，即可正常建立 HTTPS 与 WSS 连接，无需更改 Cloudflare 任何配置！

## 方案二：URL 快速指定中继（免改 DNS）

如果你配置了备用加速节点（如通过国内服务器反代或配置了优选域名的二级域名 `fast.136521.xyz`），普通玩家无需改动 hosts，直接在浏览器网址后加上参数：

```text
https://sts2.136521.xyz/?relay=https://fast.136521.xyz
```

游戏会自动将该加速地址保存到本地储存（`localStorage['sts2_relay']`），后续所有建房和 WebSocket 连接将直接通过该加速节点建立。

## 方案三：当前机房节点标识查看

在多人联机大厅左上角铭牌的 Ping 标签旁，已支持实时展示当前接入的 Cloudflare 机场三字码（IATA Code）：
- `• 68ms (HKG)`：表示成功接入香港节点（优秀）
- `• 75ms (NRT)`：表示接入日本东京节点（良好）
- `• 210ms (SJC)`：表示当前运营商走普通路由进入了美西圣何塞（建议切换优选 IP）
